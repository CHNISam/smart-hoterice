# SmartRice Platform 版本路线图

> 对齐论文、PRD、原型，严格按版本推进。每个版本必须测试全绿才可进入下一版本。

---

## V0.1.0 - 项目骨架 + 数据库基线 + 后台登录

**目标**：建立可编译、可运行、可登录的最小骨架

**包含**：
- 后端多模块工程骨架（SpringBoot 3.x + MyBatis + MySQL 8.0）
- 论文 12 个核心表 DDL + 补充表（category、brand、spec、attr、coupon 占位）
- 种子数据（admin 账号、角色、权限、商品分类、测试服务点、司机、片区）
- 后台首页可查看种子数据基线概览（只读核对，不含完整 CRUD）
- 后台管理端 Vue 3 + Vite + Element Plus（登录页 + 主布局骨架）
- Admin 登录/登出/鉴权接口（JWT）
- RBAC 权限基础

**不包含**：
- 商品管理 CRUD
- 客户端小程序
- 司机端
- 订单/购物车/支付
- AI 助手
- 优惠券/会员业务逻辑（仅 DDL 占位）

---

## V0.2.0 - 商品管理 + 客户端商品浏览 + 服务点基础

**目标**：后台可管理商品与基础履约数据，客户端可浏览商品与服务点

**包含**：
- 后台商品 CRUD（上下架、分类、规格、属性）
- 后台服务点管理
- 后台配送片区管理
- 后台服务点商品绑定
- 客户端商品浏览接口（分类列表、商品列表/详情、服务点列表、按服务点筛选商品）

**不包含**：
- 购物车、下单、支付
- 司机端
- 批次调度
- AI 助手
- 客户端微信小程序/H5 正式 UI

---

## V0.3.0 - 订单闭环 + 购物车 + 批次调度 + 司机端

**目标**：打通从下单到配送的完整业务闭环

**包含**：
- 客户端购物车 + 提单结算
- 订单状态全流程管理
- 服务点与地址履约校验（坐标距离计算）
- 后台订单管理
- 后台批次调度（区域聚合、建批、派单）
- 司机端微信小程序（登录、批次查看、送达/异常上报、收款码展示）
- 后台数据看板（ECharts 基础图表）

**不包含**：
- 真实微信支付对接（模拟支付）
- AI 助手
- 优惠券完整业务

---

## V0.4.0 - 双智能助手 AI MVP

**目标**：完成论文和 PRD 要求的 AI 检索增强问答能力

**包含**：
- Elasticsearch 检索底座（索引结构、chunk、metadata、场景过滤）
- 知识入库能力（PDF、Word、Markdown、Excel）
- C 端助手（选米问答、规则解释、推荐卡片、边界控制）
- B 端助手（业务问答、来源展示、默认折叠检索依据）
- B 端知识库管理页（上传、启停、删除、chunk 数、最近索引时间）
- Query routing（问候、澄清、检索回答、拒答、收口）
- 最小评测集与回归机制

**不包含**：
- 通用闲聊机器人
- 实时数据问答
- AI 修改业务状态

---

## V0.5.0 - 打磨 + 答辩准备（如需要）

**目标**：全链路打磨、查漏补缺、答辩演示准备

**可能包含**：
- 优惠券基础功能（如论文答辩需要）
- UI 细节优化
- 测试覆盖补充
- 演示数据准备
- 部署文档

---

## 版本规则

1. 严格按版本顺序推进，当前版本未验收通过不进入下一版本
2. 每个版本必须先有 testcase，再写代码
3. 代码开发到测试用例全绿后，提交到 develop 分支待审
4. 审核通过后合入 release
5. 版本号只用 feature version（V0.x.0），patch version 留给修 bug
